# LitGra AI

LitGra AI is a responsive front-end landing page for an AI creative studio.

## Features

- Dark, modern AI-studio design
- Responsive layout for desktop and mobile
- Creative tools section
- Prompt input studio
- Smooth navigation
- No external dependencies

## Run locally

Open `index.html` directly in a browser.

## Deploy with GitHub Pages

1. Create a GitHub repository, for example `litgra-ai`.
2. Upload `index.html` and this `README.md`.
3. Commit the files to your branch (usually `main`).
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` and `/ (root)`.
7. Save and wait for GitHub Pages to publish the site.

## Important

The current Generate button is a front-end placeholder. It does not call an AI API yet. An API/backend can be connected later.
